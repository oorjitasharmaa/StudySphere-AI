# StudySphere AI 

AI-powered study workspace built with Flask, SQLite, PyPDF and Groq.

## Features
- Secure signup/login/logout with password hashing
- User-specific documents and study history
- PDF validation and safe uploads
- AI study guides
- Quiz generation
- Chat with selected notes
- Dashboard analytics
- Friendly error handling

## Local setup
1. Create a virtual environment
2. Install requirements: `pip install -r requirements.txt`
3. Set `GROQ_API_KEY`
4. Run: `python app.py`

## Render environment variable
`GROQ_API_KEY=your_key`
